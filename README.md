## Entry

**Doomscroll** — one word, ten characters.

The whole internet in a single word: the endless scroll. A real, widely
known word that is funny and true at the same time — not the first word
that comes to mind, but the one that lands in a single beat.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, no trailing
newline). Python standard library only — no network, deterministic.
